## How to call a skill

Use the `skill` tool with the exact ID, or just ask naturally and the matching skill is loaded by its description.

- Exact: `use the yt-script skill`
- Natural: `write me a YouTube script about ...` → `yt-script`
- Multiple: `use yt-script, scene-craft and choreograph to build this`

## Multi-skill recipes by video scenario

### 60-second product/feature explainer

**Chain:** `premise-workshop` → `yt-script` → `scene-craft` → `html-explainer-video` → `choreograph` → `caption-animation` → `soundtrack` → `video-delivery-specs`

Lock the one idea, write the 130–160 word script, storyboard 5–7 scenes, build word-clocked HTML scenes, choreograph entrances, caption, score, export 16:9 + 9:16.

### 8–15 minute YouTube essay / video essay

**Chain:** `premise-workshop` → `plot-structure` → `research` → `chapter-writing`/`scene-craft` → `line-editing` → `voice-style` → `video-director` → `animated-infographic`/`diagram-animation` → `beat-sync-editing` → `yt-package`

Build a long-form arc, fact-check, write section scripts, direct each section as code-rendered scenes, cut to narration, package the click surface.

### SaaS/product demo video

**Chain:** `product-demo-video` → `html-explainer-video` → `html-demo` → `choreograph` → `micro-interaction` → `caption-animation` → `soundtrack`

Use real UI or a simulated HTML window, animate cursor/clicks/zooms, keep transitions quiet, caption the feature names, add UI sounds.

### Data / chart explainer

**Chain:** `chart-animation` → `animated-infographic` → `diagram-animation` → `motion-art-direction` → `animation-principles` → `manim` → `soundtrack`

Turn the dataset into a visual argument, animate bars/lines/counters, use Manim for math, keep one motion language.

### Faceless documentary / story explainer

**Chain:** `premise-workshop` → `plot-structure` → `scene-craft` → `voice-style` → `research` → `generative-illustration` → `map-animation`/`photo-slideshow` → `soundtrack` → `video-director`

Write a narrative arc, source the facts, generate illustration/photo/map visuals, direct the film, score it.

### Whiteboard / hand-drawn explainer

**Chain:** `whiteboard-animation` → `explainer-video` → `scene-craft` → `line-editing` → `caption-animation` → `soundtrack`

Draw-on SVG scenes, a marker hand, staggered reveals, narration-led timing, captions.

### Motion-graphics / kinetic-type tutorial

**Chain:** `animation-principles` → `emil-design-eng`/`animate` → `kinetic-typography` → `choreograph` → `svg-animation` → `gsap-core`/`gsap-timeline` → `soundtrack`

Design the motion language, animate type and shapes, choreograph the sequence, sync SFX.

### Launch / hype film

**Chain:** `launch-video` → `motion-art-direction` → `promo-video` → `logo-animation` → `youtube-intro-outro` → `soundtrack` → `video-delivery-specs`

Hook → tease → reveal → feature montage → end card; brand sting and multi-aspect export.

### Shorts / Reels cutdown from a long video

**Chain:** `yt-shorts` → `short-form-video` → `html-reel` → `caption-animation` → `beat-sync-editing` → `video-delivery-specs`

Find self-contained moments, rewrite the first 3 seconds, rebuild vertical scenes, burn captions, export 9:16.

### AI avatar / talking-head explainer

**Chain:** `talking-head` → `create-ai-avatar` → `elevenlabs-tts` → `talking-head-b-roll` → `caption-animation` → `soundtrack`

Generate the presenter and voice, then add b-roll graphics over the spoken track.

### Presentation / pitch video

**Chain:** `presentation-video` → `animated-infographic` → `chart-animation` → `motion-art-direction` → `caption-animation` → `soundtrack`

Rebuild slides as motion scenes, reveal builds in sequence, sync to per-slide narration.

### Reference-match / style transfer

**Chain:** `video-to-superprompt` → `motion-art-direction` → `animation-principles` → `choreograph` → `video-director`

Extract the reference's story, layout, motion and transitions, then rebuild it in your own brand.

### Shot-card promo film (video-shotcraft)

**Chain:** `video-shotcraft` → `choreograph` → `caption-animation` → `soundtrack` → `yt-package`

Capture the real pages, storyboard from the shot-card library, implement in Remotion, sync to the beat, add SFX, run frame QA; deliver the MP4 plus the Motion Workbench for re-edits. Use `moneyprinterturbo-video` earlier if you want a topic→MP4 sketch to react to.

### Quality pass before publishing

**Chain:** `review-animations` → `workflow-score-to-target` → `yt-retention` → `yt-package` → `video-delivery-specs`

Critique the motion, score the cut, predict the drop-off, lint the title/thumbnail, check export specs.

## Practical notes

- **Script first, visuals second.** `yt-script` / `premise-workshop` / `line-editing` are cheaper than rebuilding scenes.
- **One motion language per video.** Let `motion-art-direction` pick the easing/timing/transition family; `choreograph` executes relationships.
- **Retention is the metric.** `yt-retention` after publishing; `yt-script` and `beat-sync-editing` before.
- **Use `html-explainer-video` for voice-led 60s films**, `video-director` for code-rendered films with QA, and `business-motion-film` when the bar is a paid commercial.
- **Authored beats assembled.** `remotion-*` skills and `video-shotcraft` make elements perform the story; `moneyprinterturbo-video` assembles stock footage + TTS at speed. Combine: a Turbo draft to lock the message, then rebuild the strong sections as authored motion.
- **The 158 earlier skills still matter**, especially `explainer-video`, `animation-principles`, `motion-art-direction`, `shot-composition`, `caption-animation`, `soundtrack`, `beat-sync-editing`, `youtube-intro-outro`, `video-delivery-specs`.
- **Fiction story skills** (`plot-structure`, `scene-craft`, `chapter-writing`, `voice-style`, `line-editing`) adapt well to narrative YouTube essays; ignore the publishing/submission ones unless you are writing a book.
